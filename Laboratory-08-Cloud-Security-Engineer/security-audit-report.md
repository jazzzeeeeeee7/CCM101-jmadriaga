# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and services only the permissions they need to perform their tasks. This helps protect cloud accounts because unnecessary permissions can create additional security risks.

## Attack Surface

An attack surface refers to the possible points where an attacker could try to access a virtual machine. Open ports, running services, and exposed applications can increase the attack surface and create more opportunities for attacks.

## Default Deny Policy

A Default Deny policy blocks incoming traffic unless a specific rule allows it. This is safer because the server accepts only approved connections instead of relying on blocking individual attackers one by one.
