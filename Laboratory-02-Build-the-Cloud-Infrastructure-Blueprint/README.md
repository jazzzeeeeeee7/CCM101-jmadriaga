# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on learning the basic parts of cloud infrastructure. We used the KillerCoda Linux environment to check the server's resources and understand how compute, storage, networking, and the operating system work together.

## Objectives

* Investigate the Linux environment using the KillerCoda terminal.
* Identify the compute, storage, networking, and operating system resources.
* Compare the services of AWS, Microsoft Azure, and Google Cloud Platform.
* Create a simple cloud infrastructure diagram.
* Practice creating technical documentation using Markdown.

## Cloud Infrastructure Components

The main cloud infrastructure components identified in this laboratory were compute, storage, networking, and the operating system. The KillerCoda server uses an Intel Xeon processor with 1 CPU core, 19 GB of disk storage, network connections, and Ubuntu 24.04.4 LTS as its operating system.

## Tools Used

The tools used in this laboratory were:

* KillerCoda Playground
* Linux Terminal
* GitHub
* Microsoft PowerPoint
* Markdown

KillerCoda was used to investigate the Linux server, while Microsoft PowerPoint was used to create the cloud infrastructure diagram. GitHub was used to store and organize the laboratory files.

## Linux Commands Executed

The following Linux commands were used to investigate the cloud server:

```text id="2ok9sy"
cat /etc/os-release
uname -r
lscpu
nproc
free -h
df -h
hostname
hostname -I
ip addr
```

These commands were used to check the operating system, kernel version, CPU, CPU cores, RAM, disk storage, mounted file systems, hostname, and IP addresses.

## Skills Learned

I learned how to inspect a Linux cloud server using basic terminal commands. I also learned how to identify different cloud infrastructure components and understand their purpose. In addition, I practiced comparing cloud providers, creating a simple infrastructure diagram, and organizing technical documentation in GitHub.
