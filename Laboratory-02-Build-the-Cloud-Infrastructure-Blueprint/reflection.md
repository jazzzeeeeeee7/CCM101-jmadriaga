# Mission Reflection

During this laboratory activity, I learned more about the basic parts of cloud infrastructure and how they work together. For me, the compute resource is one of the most important components because it processes commands and runs applications on the server. Without it, the system would not be able to perform the tasks needed by users and applications.

I also learned how Linux supports cloud computing. Linux provides an operating system that can be used to manage cloud servers and their resources. By using the Linux terminal, I was able to check the CPU, RAM, storage, hostname, IP address, and other information about the server. The commands helped me understand the actual resources available in the KillerCoda environment.

Technical documentation is also important before deploying infrastructure because it keeps the information organized and easy to understand. It allows engineers to know the available resources and makes it easier to manage or troubleshoot the system when problems happen.

During this activity, I learned new skills such as using Linux commands to investigate a cloud server and identifying compute, storage, networking, and operating system resources. I also learned how to compare AWS, Microsoft Azure, and Google Cloud Platform and create a simple cloud infrastructure diagram.

Lastly, my GitHub portfolio improved because I added another laboratory activity with organized files and documentation. This activity helped me practice using Markdown and organizing my work properly. It also gave me a better understanding of how cloud infrastructure is investigated and documented.
