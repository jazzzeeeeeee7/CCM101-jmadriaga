# Cloud Provider Comparison

## Cloud Infrastructure Services

| Infrastructure Component             | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                              | Amazon EC2 | Azure Virtual Machines | Google Compute Engine       |
| Storage                              | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                           | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM    | Microsoft Entra ID     | Google Cloud IAM            |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS offers a very broad range of cloud services. It provides many options for computing, storage, networking, security, databases, and other cloud needs.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with Microsoft products and services. It also provides tools that can make it easier for organizations already using Microsoft technologies.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its AI and machine learning services. It also provides strong support for Kubernetes through Google Kubernetes Engine (GKE).

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer compute, storage, networking, and identity management services. They also allow organizations to use cloud resources without having to maintain all the physical hardware themselves.
