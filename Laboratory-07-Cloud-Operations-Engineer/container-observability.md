# Container Observability

## Application Logs

The `docker logs client-website` command displays the logs generated by the Nginx container. These logs help identify successful website requests and errors when users try to access pages.

## HTTP 404 Error Log

```text
172.17.0.1 - - [11/Oct/2026:08:42:34 +0000] "GET /hidden-admin-page HTTP/1.1" 404 153 "-" "curl/8.5.0" "-"
```

## Why Application Logs Are Important

Application logs help engineers identify failed requests and understand what happened when an error occurred. They are useful for troubleshooting because they show request details and help locate problems that need to be investigated.
