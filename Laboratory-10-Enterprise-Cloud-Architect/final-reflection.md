# Final Reflection – The Enterprise Cloud Architect

This laboratory activity was a great learning experience because it allowed me to apply my knowledge of cloud computing through an actual project. I learned how to build and manage a cloud storage system using Nextcloud and MariaDB inside an Ubuntu Server virtual machine with Oracle VM VirtualBox. Through this activity, I also became more familiar with Docker and Docker Compose and how they help simplify the installation and management of different services.

During the process, I realized that setting up a cloud environment requires patience and attention to detail. Each component must be properly configured to ensure that the entire system works as expected. I experienced some difficulties, particularly with network configuration, connecting the containers, and accessing Nextcloud through my Windows browser. These challenges helped me understand the importance of troubleshooting and checking configurations whenever a problem occurs.

Another important lesson I gained was the role of security and automation in server management. I learned how to configure the UFW firewall to limit unnecessary network access and protect the services running on the server. I also created a Bash backup script and used Cron to schedule automatic backups. This activity showed me that automating important tasks can make server management easier and help prevent data loss. Additionally, I tested the persistence of stored files by restarting the containers and checking if my uploaded files were still accessible.

Through this laboratory, I understood that managing an enterprise cloud environment involves several important responsibilities, including networking, security, data storage, backup management, and maintenance. All these components must work together to provide a stable and reliable system. Even though I encountered some errors and difficulties, I was able to overcome them by carefully following the procedures and applying what I learned.

In the future, I would like to improve this project by implementing HTTPS, creating additional backup copies on external storage, and adding better monitoring and verification for backup operations. These improvements could provide stronger security and better protection for stored information. Overall, this activity strengthened my understanding of cloud infrastructure and gave me practical experience in using Linux, Docker, virtualization, and automation. It also helped me appreciate the knowledge and skills needed to become an effective cloud administrator or enterprise cloud architect.
