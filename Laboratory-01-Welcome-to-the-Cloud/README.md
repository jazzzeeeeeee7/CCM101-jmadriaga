 Mission Overview

This laboratory activity gave me hands-on experience with a cloud-based Linux environment through KillerCoda. I learned how to work with Ubuntu, use basic Linux commands, manage users, inspect system resources, and organize files. I also applied these skills in preparing my Cloud Computing portfolio on GitHub.

# Objectives

* Use a cloud-based Linux environment through KillerCoda.
* Practice basic Linux commands and navigation.
* Create and manage a Linux user account.
* Collect important system information.
* Create and organize files and directories.
* Use Markdown for technical documentation.
* Set up and manage a GitHub repository for cloud computing activities.

# Activities Performed

* Started an Ubuntu 24.04 environment using KillerCoda.
* Created a new Linux user and provided sudo privileges.
* Switched to and logged in using the created user account.
* Verified the current username, directory, and hostname.
* Examined the Linux distribution and kernel information.
* Checked the CPU, memory, and disk usage of the system.
* Created and arranged Markdown files and directories.
* Created a GitHub repository for my Cloud Computing portfolio.
