# Mission 5: The Cloud Data Engineer

## Mission Overview

This laboratory activity introduced me to cloud storage and the different ways data can be stored. I learned about Block Storage, File Storage, and Object Storage. I also deployed a MinIO object storage server using Docker, created a bucket, and uploaded a sample file.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy an S3-compatible object storage server using MinIO and Docker.
- Access the MinIO Web Console through port 9001.
- Create a storage bucket and upload a sample file.
- Document the cloud storage deployment using Markdown.

## Tools Used

- KillerCoda Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

I learned how to deploy an object storage server using Docker and how to access it through a web console. I also learned how to create a bucket and upload an object to MinIO. This activity helped me understand how object storage can be used for storing large amounts of files such as images.
