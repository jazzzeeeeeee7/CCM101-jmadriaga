# Automation Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains Linux commands arranged to perform tasks automatically. The `#!/bin/bash` line, called a shebang, tells the system to use Bash to run the script.

## 2. Variables

Variables store values, such as folder paths, so they can be reused in a script. For example, using `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing the same path in several commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time or interval. It is useful in cloud operations because it can automate repeated tasks, such as creating backups, without requiring someone to run them manually.
