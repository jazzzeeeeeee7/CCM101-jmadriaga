# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides tools and services that businesses and developers can use to create, deploy, and manage applications and other IT resources through the cloud.

## Global Infrastructure

Azure has cloud infrastructure distributed across different geographic locations. It uses Regions and Availability Zones to provide reliable cloud services and help organizations choose locations that are suitable for their applications and users.

## Cloud Management Console

The Azure portal is a web-based management interface for working with Azure resources. Users can create and configure services, check resource usage, monitor applications, and manage their cloud environment from one place.

## Four Core Services

1. **Azure Virtual Machines** - Provides virtual computers that can be used to run applications, operating systems, and other workloads.

2. **Azure Blob Storage** - A cloud storage service used for storing large amounts of unstructured data such as files, images, videos, and backups.

3. **Azure Virtual Network** - Allows users to create a private network for connecting and controlling Azure resources.

4. **Microsoft Entra ID** - Provides identity and access management for users, applications, and other resources in an organization.

## Three Advantages

1. **Microsoft Integration** - Azure works well with Microsoft products and technologies, making it useful for organizations already using Microsoft services.

2. **Scalable Resources** - Organizations can adjust their cloud resources based on changes in workload and business requirements.

3. **Enterprise Support** - Azure provides services and tools designed to support the needs of large organizations and business environments.

## Typical Enterprise Use Cases

Enterprises can use Azure to host business applications, operate virtual servers, store company data, and connect cloud resources through virtual networks. It is also commonly suitable for organizations that already depend on Microsoft technologies and want to move some of their existing systems to the cloud.
