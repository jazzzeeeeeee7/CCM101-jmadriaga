# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon that offers a large collection of services for building and running applications. Instead of relying only on physical computers, users can obtain computing power, storage, databases, networking, and security tools through AWS.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. A Region represents a specific geographic area, while Availability Zones are separate locations within a Region. This setup allows businesses to place their applications in suitable locations and reduce the effect of failures in a single location.

## Cloud Management Console

The AWS Management Console is an online interface where users can work with their AWS account and services. It provides access to different cloud resources and allows users to create, configure, monitor, and manage those resources from a web browser.

## Four Core Services

1. **Amazon EC2** - A computing service that lets users create virtual machines for running applications and workloads.

2. **Amazon S3** - A storage service designed for keeping files, backups, media, and other types of data as objects.

3. **Amazon VPC** - A networking service that provides an isolated virtual network where AWS resources can be organized and connected.

4. **AWS IAM** - A security service used to control who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

1. **Flexible Services** - AWS offers many services that can be combined depending on the technical needs of an organization.

2. **Worldwide Infrastructure** - Its infrastructure is distributed across different locations, giving businesses more choices for where to deploy their applications.

3. **Resource Scalability** - Cloud resources can be adjusted as workload requirements change, making it easier for businesses to handle increases or decreases in demand.

## Typical Enterprise Use Cases

Large organizations can use AWS to host business applications and websites, store important company information, and operate virtual computing environments. AWS can also be used for backup and recovery, databases, data processing, and applications that need infrastructure capable of handling changing workloads.
